How statuses are assigned

Each function is classified from its current IDB name. Placeholder means the name is one of the auto-naming families and says nothing about what the function is. Partial means the owner (class or subsystem) is real but the method part is a slot number, helper tag or address. Named is everything else.

placeholder = ^(Group[0-9A-F]{8}|Class8[0-9A-F]{7}|SharedVf\d+|Unreferenced|DataRef_|UsesStr_|Common_(util|shared|helper)|FnTable8|MultiRef|(Get|Set)(U|S|F)?(8|16|32|64)_[0-9A-F]+$|sub_|nullsub_) partial = not placeholder, and matches (8[0-9A-F]{7}|_vf\d+|_Slot\d+|_(util|helper|shared|wrapper|callback)$) named = everything else

A name only moves out of placeholder when there is proof for it: a string where the function names itself, RTTI, an import or a library signature. As of the 2026-11-21 snapshot, the evidence inside the IDB is used up, so the remaining placeholders need outside proof such as a symbol donor build or library signatures.

Update the function list
  1. In IDA, open the Functions window (Shift+F3), click inside it, press Ctrl+A, then Ctrl+C.
  2. Paste anywhere on this page, drop a saved list onto the map, or use Open function list…. This only changes your own view.
  3. To update the hosted page for everyone, save the same text as functions.txt next to index.html and upload both.

Accepted formats: IDA Functions-window copy (name, segment, start, length…), or JSON objects with addr, name and size.
